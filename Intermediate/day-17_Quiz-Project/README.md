# 🐍 Day 17 – Quiz Project (OOP)

Welcome to **Day 17** of the Python learning journey!
Today focuses on deepening your understanding of **Object-Oriented Programming** by building a structured **Quiz Game application**.

You will learn how to design classes, manage program flow using objects, and structure a multi-file Python project.

---

## 📚 Topics Covered

- Creating custom classes
- Using objects to manage program state
- Separating logic into multiple modules
- Structuring real-world style applications
- Working with external datasets
- Implementing game logic using OOP

---

## 📂 Files Overview

| File / Folder                    | Description                                                         |
| -------------------------------- | ------------------------------------------------------------------- |
| `01-create-class.py`             | Introduction to creating your own Python class and object instances |
| `02-quiz-game/`                  | Full Quiz Game project built using Object-Oriented Programming      |
| `02-quiz-game/main.py`           | Main program that runs the quiz game                                |
| `02-quiz-game/question_model.py` | Defines the Question class used to represent quiz questions         |
| `02-quiz-game/quiz_brain.py`     | Contains the quiz logic, scoring system, and question flow control  |
| `02-quiz-game/data.py`           | Dataset containing the quiz questions and answers                   |

---

## 🎯 Learning Goal

By the end of Day 17, you should be able to:

- Create and use custom Python classes
- Structure a multi-file OOP project
- Manage program flow using objects
- Separate data, logic, and execution layers
- Build interactive console-based applications
