# 🐍 Day 22 – Pong Game

Welcome to **Day 22** of the Python learning journey!
Today you will build a classic **Pong Game**, applying Object-Oriented Programming, game loops, collision detection, and graphical interaction using **Turtle graphics**.

This project focuses on structuring a multi-class game architecture and implementing real-time game mechanics.

---

## 📚 Topics Covered

- Structuring a full game using OOP
- Managing multiple game objects
- Collision detection (paddle, wall, scoring)
- Implementing real-time movement and physics logic
- Creating reusable graphical components
- Designing interactive two-player games

---

## 📂 Files Overview

| File            | Description                                                           |
| --------------- | --------------------------------------------------------------------- |
| `main.py`       | Main game loop, screen setup, and coordination of all game components |
| `paddle.py`     | Paddle class handling player movement and controls                    |
| `ball.py`       | Ball class managing movement, bouncing logic, and speed changes       |
| `scoreboard.py` | Scoreboard class for tracking and displaying player scores            |

---

## 🎯 Learning Goal

By the end of Day 22, you should be able to:

- Structure a complete OOP game project
- Implement collision and scoring systems
- Manage multiple interactive objects
- Build real-time graphical applications
- Design reusable and modular game logic

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-22_Pong-Game
python3 main.py
```

---

## 🧠 Main Project

The **Pong Game** simulates:

- Two paddles controlled by different players
- A bouncing ball with collision physics
- Wall and paddle collision detection
- Score tracking for both players
- Increasing difficulty as the game progresses

Try enhancing it by:

- Adding sound effects
- Implementing single-player AI mode
- Adding game restart functionality
- Improving visual styling and animations
- Adding winning conditions
