# 🐍 Day 21 – Snake Game (Part 2)

Welcome to **Day 21** of the Python learning journey!
Today continues the development of the classic **Snake Game**, expanding the project with **food mechanics, scoring, and collision detection**.

This part builds on the movement system from Part 1 and transforms it into a more complete and playable game.

---

## 📚 Topics Covered

- Expanding OOP game architecture
- Collision detection (food, walls, self)
- Managing game state and scoring
- Creating reusable game components
- Structuring multi-class graphical applications
- Improving interactive game design

---

## 📂 Files Overview

| File            | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| `main.py`       | Main game loop, screen setup, and integration of all game components |
| `snake.py`      | Snake class handling movement, growth, and direction logic           |
| `food.py`       | Food class responsible for spawning and repositioning food objects   |
| `scoreboard.py` | Scoreboard class for displaying score and handling game over logic   |

---

## 🎯 Learning Goal

By the end of Day 21, you should be able to:

- Extend an existing OOP project cleanly
- Implement collision detection in games
- Manage dynamic game state
- Structure larger graphical applications
- Design modular and reusable game components

## 🧠 Project Focus

In **Part 2 of the Snake Game**, you will:

- Add food that the snake can eat
- Grow the snake dynamically
- Track and display the current score
- Detect collisions with walls
- Detect collisions with the snake’s own body
- Implement a game over state

Try enhancing it by:

- Adding high score persistence
- Increasing difficulty over time
- Adding sound effects or animations
- Creating a restart system
- Improving visual styling
