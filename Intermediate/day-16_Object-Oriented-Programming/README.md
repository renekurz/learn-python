# 🐍 Day 16 – Object-Oriented Programming (OOP)

Welcome to **Day 16** of the Python learning journey!
Today introduces the core concepts of **Object-Oriented Programming (OOP)** and shows how to structure larger applications using **classes, objects, and modular design**.

You will first learn the fundamentals of creating objects and using external packages, and then apply these concepts in an **OOP Coffee Machine project**.

---

## 📚 Topics Covered

- Constructing objects from classes
- Understanding attributes and methods
- Importing and using external Python packages
- Structuring larger applications with OOP
- Separating responsibilities across modules
- Designing scalable program architecture

---

## 🎯 Learning Goal

By the end of Day 16, you should be able to:

- Understand the basics of Object-Oriented Programming

- Apply OOP concepts to real-world style applications

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example (OOP Coffee Machine):

```bash
cd day-16_Object-Oriented-Programming/03-coffee-machine-in-oop
python3 main.py
```

## 🧠 Main Project

The **OOP Coffee Machine** simulates:

- Selecting drinks from a structured menu
- Managing machine resources using classes
- Handling payments and calculating change
- Tracking profit and generating reports
- Using modular program architecture

Try enhancing it by:

- Adding persistence (save profit/resources to file)
- Implementing a GUI version
- Adding user accounts or admin mode
- Extending the menu dynamically
- Writing unit tests for each class
