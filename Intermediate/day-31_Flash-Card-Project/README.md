# 🐍 Day 31 – Flash Card Project

Welcome to **Day 31** of the Python learning journey!
Today you will build a complete **Flash Card learning application** using **Tkinter**, combining GUI development, file handling, and data persistence.

This project simulates a language learning tool that helps users memorize vocabulary using timed flashcards.

---

## 📚 Topics Covered

- Building advanced GUI applications with Tkinter
- Working with timers and delayed events (`after`)
- Reading and writing CSV data with Pandas
- Managing application state across sessions
- Updating UI dynamically
- Structuring full real-world applications

---

## 🧠 Main Project

The **Flash Card App** includes:

- Displaying random vocabulary words
- Flipping cards after a time delay
- Tracking known vs unknown words
- Saving progress between sessions
- Interactive GUI with buttons and images

Try enhancing it by:

- Adding multiple languages
- Allowing custom word lists
- Tracking learning statistics
- Adding sound pronunciation
- Improving UI animations and design
