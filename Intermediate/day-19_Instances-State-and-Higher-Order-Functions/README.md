# 🐍 Day 19 – Instances, State & Higher Order Functions

Welcome to **Day 19** of the Python learning journey!
Today focuses on understanding **object instances**, how objects maintain **state**, and how to use **higher-order functions** for event handling and interactive programs.

You will apply these concepts using graphical projects built with **Turtle graphics**.

---

## 📚 Topics Covered

- Object instances and object state
- How objects store and update internal data
- Event listeners and key bindings
- Higher-order functions in Python
- Interactive GUI-style console programs
- Structuring event-driven applications

---

| File                      | Description                                                         |
| ------------------------- | ------------------------------------------------------------------- |
| `01-etch-a-sketch-app.py` | Interactive drawing app using keyboard controls and turtle graphics |

## 🎯 Learning Goal

By the end of Day 19, you should be able to:

- Understand how object instances maintain state
- Use event listeners and key bindings
- Apply higher-order functions in real programs
- Build interactive graphical applications
- Manage multiple objects simultaneously
