# 🐍 Day 30 – Errors, Exceptions & JSON Data

Welcome to **Day 30** of the Python learning journey!
Today focuses on writing more **robust and reliable programs** by handling **errors and exceptions**, and working with structured data using **JSON**.

You will also improve a previous project by upgrading the **Password Manager** to use JSON for better data handling.

---

## 📚 Topics Covered

- Handling exceptions with try/except
- Catching specific error types
- Raising your own exceptions
- Debugging common runtime errors
- Working with JSON data (read/write/update)
- Improving application reliability
