# 🐍 Day 29 – Password Manager (Tkinter GUI)

Welcome to **Day 29** of the Python learning journey!
Today you will build a practical **Password Manager application** using **Tkinter**, combining GUI development with file handling and data storage.

This project simulates a simple tool for generating, saving, and managing passwords securely.

---

## 📚 Topics Covered

- Building full GUI applications with Tkinter
- Handling user input through forms
- Working with files for data storage
- Generating random secure passwords
- Structuring real-world applications
- Improving user experience with validation

---

## 📂 Files Overview

| File       | Description                                                         |
| ---------- | ------------------------------------------------------------------- |
| `main.py`  | Main application containing GUI logic and password manager features |
| `data.txt` | File used to store saved website, email, and password data          |
| `logo.png` | Image asset used in the GUI interface                               |

_(macOS system files are ignored as they are not part of the learning material.)_

## 🎯 Learning Goal

By the end of Day 29, you should be able to:

- Build complete GUI applications
- Handle and validate user input
- Store and retrieve data from files
- Generate secure random data
- Structure practical, real-world tools

## 🧠 Main Project

The **Password Manager** includes:

- Input fields for website, email, and password
- Random password generator
- Saving credentials to a file
- Basic validation before saving data
- GUI layout using Tkinter widgets

Try enhancing it by:

- Encrypting stored passwords
- Using JSON instead of plain text
- Adding search functionality
- Implementing copy-to-clipboard feature
- Improving UI/UX design
