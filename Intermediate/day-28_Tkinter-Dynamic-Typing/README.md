# 🐍 Day 28 – Tkinter, Dynamic Typing & Pomodoro App

Welcome to **Day 28** of the Python learning journey!
Today focuses on building a more advanced **GUI application** using Tkinter while understanding Python concepts like **dynamic typing** and working with the **Canvas widget**.

You will apply these concepts in a practical project: a **Pomodoro Timer application**.

---

## 📚 Topics Covered

- Working with the Tkinter Canvas widget
- Dynamic typing in Python
- Updating UI elements dynamically
- Managing time-based events (timers)
- Structuring larger GUI applications
- Building productivity tools
