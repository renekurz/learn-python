# 🐍 Day 20 – Snake Game (Part 1)

Welcome to **Day 20** of the Python learning journey!
Today begins the development of a classic **Snake Game**, focusing on structuring a graphical game using **Object-Oriented Programming** and **Turtle graphics**.

In this first part, you will build the **core snake movement system** and establish the game loop structure.

---

## 📚 Topics Covered

- Structuring game projects using OOP
- Managing multiple object instances
- Creating and updating game state
- Building a continuous game loop
- Handling keyboard input for movement
- Separating game logic into modules

---

## 📂 Files Overview

| File       | Description                                                                |
| ---------- | -------------------------------------------------------------------------- |
| `main.py`  | Main game loop, screen setup, and keyboard control handling                |
| `snake.py` | Snake class implementation responsible for movement and segment management |

---

## 🎯 Learning Goal

By the end of Day 20, you should be able to:

- Structure a graphical game using OOP
- Implement object-based movement logic
- Create continuous animation loops
- Handle user input in real-time
- Design modular game architecture

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-20_Snake-Game-Part-1
python3 main.py
```

## 🧠 Project Focus

In **Part 1 of the Snake Game**, you will:

- Create the snake using multiple turtle segments
- Implement forward movement logic
- Control direction using keyboard input
- Build the foundation for collision detection and scoring

Try enhancing it by:

- Adjusting snake speed dynamically
- Improving movement smoothness
- Adding boundary visualization
- Preparing structure for food and score system
