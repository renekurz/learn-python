# Learn Python 🐍 (100 Days of Code)

A complete **100‑day Python learning journey** covering beginner → advanced → professional portfolio projects.

This repository follows a structured curriculum including:

* Python fundamentals
* OOP & intermediate concepts
* GUI development
* Web scraping & automation
* APIs & backend development with Flask
* Data science & machine learning
* Real‑world portfolio projects

---

## 📚 About This Repository

This repo documents my progress through a full Python developer path.
Each folder represents a **day or section** of learning with:

* Notes
* Exercises
* Mini‑projects
* Capstone projects

Goal: Build strong **real‑world Python skills** through consistent daily coding.

* Capstone projects

* HTML, CSS, Bootstrap

### 🟣 Advanced Data Science (Day 61–81)

* SQL & SQLAlchemy

* Data visualization (Matplotlib, Plotly, Seaborn)
* Machine learning projects

### 🏆 Professional Portfolio (Day 82–100)

* Real‑world production projects
* Automation tools
* Web apps
* GUIs
* APIs
* Data science projects
