# 🐍 Day 07 – Hangman Project

Welcome to **Day 07** of the Python learning journey!
Today focuses on building a complete **Hangman game**, combining loops, conditionals, lists, and modular code structure.

---

## 📚 Topics Covered

- Building a larger multi-file project
- Using lists to manage game state
- Tracking user guesses
- Improving user experience
- Structuring game logic step by step
- Using external modules for cleaner code

---

## 📂 Files Overview

| File                                | Description                                      |
| ----------------------------------- | ------------------------------------------------ |
| `01-picking-random-words.py`        | Selecting a random word for the Hangman game     |
| `02-checking-answers.py`            | Checking user guesses against the chosen word    |
| `03-replace-blanks-with-guesses.py` | Updating the displayed word with correct guesses |
| `04-checking-if-player-won.py`      | Determining win conditions                       |
| `05-keep-track-of-player-live.py`   | Tracking player lives and game progress          |
| `06-improving-user-experience.py`   | Final improvements and polish to gameplay        |
| `hangman_art.py`                    | ASCII art for Hangman visuals                    |
| `hangman_words.py`                  | Word list used in the game                       |
| `Hangman_Flowchart.png`             | Visual flowchart of the Hangman game logic       |

---

## 🎯 Learning Goal

By the end of Day 07, you should be able to:

- Structure larger Python programs across multiple files
- Manage game state using lists and variables
- Implement complete game logic
- Improve user interaction and experience
- Understand step-by-step program development

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-07_Beginner_Hangman
python3 06-improving-user-experience.py
```
