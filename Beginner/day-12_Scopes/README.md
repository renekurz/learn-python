# 🐍 Day 12 – Scope, Namespaces & Number Guessing Game

Welcome to **Day 12** of the Python learning journey!
Today focuses on understanding **scope**, how Python handles **namespaces**, and how to structure programs using **global vs local variables**.

You’ll apply these concepts in a full mini-project: the **Number Guessing Game**.

---

## 📚 Topics Covered

- Local vs global scope
- Python namespaces
- Modifying global variables
- Constants in Python
- Structuring program logic with scope awareness
- Building a full interactive guessing game

---

## 📂 Files Overview

| File                                  | Description                                                   |
| ------------------------------------- | ------------------------------------------------------------- |
| `01-namespaces-local-global-scope.py` | Introduction to namespaces and how local/global scope works   |

---

## 🎯 Learning Goal

By the end of Day 12, you should be able to:

- Understand how Python handles variable scope
- Distinguish between local and global variables
- Use constants correctly in programs
- Structure larger logic flows more cleanly
- Build an interactive game using functions and loops

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-12_Scopes
python3 05-number-guessing-game.py
```

## 🧠 Mini Project

The **Number Guessing Game** challenges the player to:

- Guess a randomly generated number
- Receive hints (too high / too low)
- Manage limited attempts based on difficulty
- Replay the game

Try enhancing it by:

- Adding a scoring system
- Tracking best performance
- Allowing custom number ranges
- Improving the user interface
