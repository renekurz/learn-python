# 🐍 Day 01 – Python Basics

Welcome to **Day 01** of the Python learning journey!
Today introduces the fundamental building blocks of Python programming.

---

## 📚 Topics Covered

- Running your first Python program
- Using the `print()` function
- String manipulation & formatting
- Getting user input with `input()`
- Working with variables
- Debugging common syntax errors

---

## 📂 Files Overview

| File                        | Description                               |
| --------------------------- | ----------------------------------------- |
| `01-hello-world.py`         | Your first Python program using `print()` |
| `02-printing-practice.py`   | Practice formatting and printing text     |
| `03-string-manipulation.py` | Working with strings and escape sequences |
| `04-debugging-practice.py`  | Fixing common syntax and logic errors     |
| `05-input-function.py`      | Getting user input from the console       |
| `06-python-variables.py`    | Introduction to Python variables          |
| `07-exercise-variables.py`  | Practice using and swapping variables     |
| `08-band-name-generator.py` | Mini project combining input + strings    |

---

## 🎯 Learning Goal

By the end of Day 01, you should be able to:

- Write and run simple Python scripts
- Print formatted output
- Take user input and use it in programs
- Understand basic variables
- Debug simple syntax mistakes

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-01_Beginner_Working-with-Variables
python3 08-band-name-generator.py
```
