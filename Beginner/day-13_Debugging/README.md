# 🐍 Day 13 – Beginner Debugging

Welcome to **Day 13** of the Python learning journey!
Today focuses on learning how to **debug Python programs effectively** by identifying, reproducing, and fixing errors.

You’ll work through several small examples that simulate common beginner mistakes and practice structured debugging techniques.

---

## 📚 Topics Covered

- How to describe and understand a bug
- Reproducing bugs consistently
- Using print statements for debugging
- Logical debugging strategies
- Fixing common beginner mistakes
- Improving problem-solving mindset

---

## 📂 Files Overview

| File                                       | Description                                             |
| ------------------------------------------ | ------------------------------------------------------- |
| `01-describe-the-problem.py`               | Learning how to clearly identify and describe a bug     |
| `02-reproduce-the-bug.py`                  | Practicing how to reliably reproduce bugs for debugging |
| `03-squash-bugs-with-a-print-statement.py` | Using print debugging to track down logical errors      |
| `04-debugging-odd-or-even.py`              | Fixing a logical bug in an odd/even number program      |
| `05-debugging-leap-year.py`                | Debugging incorrect leap year logic                     |
| `06-debugging-fizz-buzz.py`                | Debugging a broken FizzBuzz implementation              |

---

## 🎯 Learning Goal

By the end of Day 13, you should be able to:

- Identify and explain program errors clearly
- Reproduce bugs consistently
- Use print statements as a debugging tool
- Fix logical errors in programs
- Approach debugging in a structured way

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-13_Debugging
python3 06-debugging-fizz-buzz.py
```

---

## 🧠 Practice Focus

Debugging is one of the **most important programming skills**.

Try improving your debugging skills by:

- Breaking problems into smaller steps
- Printing intermediate values
- Reading error messages carefully
- Testing edge cases
- Explaining the bug out loud before fixing it

---

Happy debugging! 🐞💻
