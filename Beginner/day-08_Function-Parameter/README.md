# 🐍 Day 08 – Function Parameters & Caesar Cipher

Welcome to **Day 08** of the Python learning journey!
Today focuses on writing reusable functions, working with function inputs, and building a multi-step **Caesar Cipher** project.

---

## 📚 Topics Covered

- Functions with inputs
- Positional vs keyword arguments
- Returning and reusing logic
- Breaking problems into smaller steps
- Encrypting and decrypting text
- Refactoring code for better structure

---

## 📂 Files Overview

| File                                    | Description                                                           |
| --------------------------------------- | --------------------------------------------------------------------- |
| `01-functions-with-inputs.py`           | Introduction to functions that take parameters                        |
| `02-life-in-weeks.py`                   | Practice project using function inputs and calculations               |
| `03-positional-vs-keyword-arguments.py` | Understanding the difference between positional and keyword arguments |
| `04-love-calculator.py`                 | Mini project using functions, strings, and logic                      |
| `05-caesar-cipher-encryption.py`        | First Caesar Cipher version focused on encryption                     |

| `07-caesar-cipher-combined.py`          | Combining encryption and decryption into one program                  |
| `08-ceaser-cipher-reorganising.py`      | Refactoring and reorganising the Caesar Cipher project                |
| `art.py`                                | ASCII art used in the Caesar Cipher project                           |

---

## 🎯 Learning Goal

By the end of Day 08, you should be able to:

- Write functions with parameters
- Understand positional and keyword arguments
- Break larger problems into smaller reusable parts
- Build and improve a multi-step project
- Refactor code to make it cleaner and easier to maintain

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-08_Function-Parameter
python3 08-ceaser-cipher-reorganising.py
```
