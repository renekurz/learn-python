# 🐍 Day 14 – Higher Lower Game

Welcome to **Day 14** of the Python learning journey!
Today focuses on building a complete **Higher Lower Game**, combining everything learned so far: functions, logic, loops, modular code, and working with external data.

This project simulates a popular comparison game where the player must guess which person has more followers.

---

## 📚 Topics Covered

- Combining multiple Python concepts into one project
- Structuring larger programs cleanly
- Using external data modules
- Random selection from datasets
- Game loop logic and score tracking
- Building interactive console applications

---

## 📂 Files Overview

| File                      | Description                                             |
| ------------------------- | ------------------------------------------------------- |
| `01-higher-lower-game.py` | Main game logic for the Higher Lower game               |
| `persons.py`              | Dataset containing people/accounts used for comparisons |
| `art.py`                  | ASCII logo and visual elements used in the game         |

## 🎯 Learning Goal

By the end of Day 14, you should be able to:

- Structure a full Python game project
- Work with external data modules
- Implement comparison-based game logic
- Maintain state and score in loops
- Build more realistic interactive applications

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-14_Beginner_Higher-Lower-Game
python3 01-higher-lower-game.py
```

## 🧠 Mini Project

The **Higher Lower Game** challenges the player to:

- Compare two randomly selected people/accounts
- Guess who has more followers
- Continue playing while guesses are correct
- Track and display the current score

Try enhancing it by:

- Expanding the dataset
- Adding difficulty levels
- Showing more detailed statistics
- Improving UI formatting
- Adding streak or high-score tracking
