# 🐍 Day 11 – Blackjack Capstone Project

Welcome to **Day 11** of the Python learning journey!
Today is a **capstone-style project** where you apply everything learned so far to build a complete **Blackjack game**.

This project focuses on combining logic, functions, loops, and program structure to simulate a real game.

---

## 📚 Topics Covered

- Applying functions in larger programs
- Game logic and rule implementation
- Working with lists and random values
- While loops for continuous gameplay
- Conditional logic for game outcomes
- Structuring a full mini-application

---

| File              | Description                                               |
| ----------------- | --------------------------------------------------------- |

## 🎯 Learning Goal

By the end of Day 11, you should be able to:

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-11_Blackjack
python3 01-blackjack.py
```

## 🧠 Capstone Project

The **Blackjack game** simulates:

- Drawing random cards
- Player vs dealer logic
- Score calculation with Ace handling
- Win / lose / draw conditions
- Option to replay the game

Try enhancing it by:

- Adding proper card deck simulation (no infinite cards)
- Showing full dealer logic step-by-step
- Improving UI and formatting
- Adding betting system
- Tracking player statistics
