# 🐍 Day 10 – Functions with Outputs & Calculator Project

Welcome to **Day 10** of the Python learning journey!
Today focuses on writing functions that **return values**, understanding **multiple return outputs**, using **docstrings**, and building a complete **Calculator project**.

---

## 📚 Topics Covered

- Functions with return values
- Storing and reusing function outputs
- Multiple return values
- Logical problem solving with functions
- Writing and using docstrings
- Building a reusable calculator program

---

## 📂 Files Overview

| File                           | Description                                                    |
| ------------------------------ | -------------------------------------------------------------- |
| `01-functions-with-outputs.py` | Introduction to functions that return values                   |
| `02-multiple-return-values.py` | Understanding how functions can return multiple outputs        |
| `03-leap-year.py`              | Practice project using functions and logical conditions        |
| `04-docstrings.py`             | Learning how to write and use docstrings in functions          |
| `05-calculator.py`             | Main project: Interactive calculator using functions and loops |
| `art.py`                       | ASCII logo used in the calculator project                      |

---

## 🎯 Learning Goal

By the end of Day 10, you should be able to:

- Write functions that return values
- Use returned data in further calculations
- Implement functions with multiple outputs
- Document functions using docstrings
- Structure and build a reusable calculator program

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-10
python3 05-calculator.py
```
