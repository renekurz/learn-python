# 🐍 Day 15 – Coffee Machine Project (Procedural Version)

Welcome to **Day 15** of the Python learning journey!
Today focuses on building a complete **Coffee Machine simulation** using procedural programming, logical structuring, and problem decomposition.

This project simulates how a real coffee machine processes orders, manages resources, and handles payments.

---

## 📚 Topics Covered

- Structuring larger procedural programs
- Managing state with variables and dictionaries
- Logical flow for real-world simulations
- Handling user input and validation
- Resource management logic
- Building multi-step console applications

---

## 📂 Files Overview

| ----------------------------------------- | ----------------------------------------------------------------------------- |

## 🎯 Learning Goal

By the end of Day 15, you should be able to:

- Structure a full procedural Python program
- Manage system state (resources, money, drinks)
- Implement real-world style logic flows
- Build interactive console simulations
- Translate program requirements into working code

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-15_Coffee-Machine
python3 01-coffee-machine.py
```

---

## 🧠 Mini Project

The **Coffee Machine** simulation includes:

- Selecting drinks (espresso, latte, cappuccino)
- Checking ingredient availability
- Processing coin input
- Returning change
- Tracking total profit
- Generating system reports

Try enhancing it by:

- Refactoring into OOP (classes)
- Saving reports to a file
- Adding refill functionality
- Improving input validation
- Creating a GUI version
