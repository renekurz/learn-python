# 🐍 Day 27 – GUI with Tkinter

Welcome to **Day 27** of the Python learning journey!
Today introduces **Graphical User Interface (GUI) development** using the **Tkinter library**.

You will learn how to create windows, add UI components, manage layouts, and build a small interactive application.

---

## 📚 Topics Covered

- Creating GUI windows with Tkinter
- Working with labels, buttons, and input fields
- Positional vs keyword arguments in UI configuration
- Handling user interaction and events
- Using layout managers (pack, place, grid)
- Building simple GUI applications

---

## 📂 Files Overview

| File                                                | Description                                                      |

| `01-creating-windows-and-labels.py`                 | Introduction to creating GUI windows and labels                  |
| `02-many-positional-arguments.py`                   | Understanding positional arguments in Tkinter components         |

| `04-buttons-entry-and-setting-component-options.py` | Working with buttons, input fields, and component settings       |
| `05-radiobuttons-scales-checkbuttons-and-more.py`   | Exploring additional Tkinter widgets and interactive controls    |
| `06-layout-managers.py`                             | Understanding layout systems (pack, grid, place)                 |
| `07-mile-to-kilometers-converter.py`                | Mini project: GUI application for converting miles to kilometers |

---

## 🎯 Learning Goal

By the end of Day 27, you should be able to:

- Create basic GUI applications using Tkinter
- Handle user input through graphical components
