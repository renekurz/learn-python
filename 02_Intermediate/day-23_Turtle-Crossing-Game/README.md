# 🐍 Day 23 – Turtle Crossing Game

Welcome to **Day 23** of the Python learning journey!
Today you will build a complete **Turtle Crossing Game**, inspired by classic arcade-style gameplay.

This project focuses on combining **Object-Oriented Programming**, **collision detection**, and **game progression mechanics** into a fully playable graphical application.

---

## 📚 Topics Covered

- Structuring larger OOP game projects
- Managing multiple moving objects
- Collision detection with dynamic obstacles
- Implementing level progression systems
- Controlling player movement via keyboard input
- Designing modular and reusable game components

---

## 📂 Files Overview

| File             | Description                                                          |
| ---------------- | -------------------------------------------------------------------- |
| `main.py`        | Main game loop, screen setup, and integration of all game components |
| `player.py`      | Player class handling movement and reset logic                       |
| `car_manager.py` | Manages creation, movement, and speed of obstacle cars               |
| `scoreboard.py`  | Scoreboard class handling level tracking and game over display       |

---

## 🎯 Learning Goal

By the end of Day 23, you should be able to:

- Structure a full OOP-based graphical game
- Implement obstacle spawning and movement systems
- Handle collision detection between multiple objects
- Implement level progression mechanics
- Design modular and scalable game architecture

## 🧠 Main Project

The **Turtle Crossing Game** simulates:

- A player-controlled turtle trying to cross the road
- Randomly spawning moving cars as obstacles
- Increasing difficulty as levels progress
- Collision detection leading to game over
- Level tracking and progression system

Try enhancing it by:

- Adding lives system
- Adding sound effects
- Implementing pause/restart functionality
- Improving graphics and animations
- Adding scoring based on time or performance
