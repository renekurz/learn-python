# 🐍 Day 25 – CSV Files & Pandas Library

Welcome to **Day 25** of the Python learning journey!
Today focuses on working with **CSV files**, performing **data analysis**, and using the powerful **Pandas library**.

You will learn how to read structured data, manipulate datasets, and build small data-driven projects.

- Filtering and aggregating data
- Building data-driven mini projects
