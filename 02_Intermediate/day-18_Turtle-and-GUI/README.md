# 🐍 Day 18 – Turtle Graphics & GUI Drawing

Welcome to **Day 18** of the Python learning journey!
Today introduces **Turtle Graphics**, a visual way to understand programming concepts by drawing shapes, patterns, and generative art.

You will learn how to control graphical objects, create visual patterns, and build creative drawing programs.

---

## 📚 Topics Covered

- Introduction to Turtle graphics
- Moving and controlling graphical objects
- Drawing geometric shapes
- Working with loops in visual programs
- Randomized movement and generative art
- Creating complex patterns and designs

---

## 📂 Files Overview

| File                                  | Description                                                   |
| ------------------------------------- | ------------------------------------------------------------- |
| `01-understanding-turtle-graphics.py` | Introduction to the Turtle module and basic movement          |
| `02-draw-a-square.py`                 | Drawing a square using turtle commands                        |
| `03-draw-a-dashed-line.py`            | Creating dashed lines with loops                              |
| `04-draw-different-shapes.py`         | Drawing multiple geometric shapes with varying sides          |
| `05-generate-a-random-walk.py`        | Generating random movement patterns                           |
| `06-draw-a-spirograph.py`             | Drawing a spirograph pattern using rotations and loops        |
| `07-spot-painting.py`                 | Creating a dot painting inspired by generative art techniques |
| `image.jpg`                           | Reference image used for the spot painting project            |

By the end of Day 18, you should be able to:
