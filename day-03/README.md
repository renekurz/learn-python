# 🐍 Day 03 – Control Flow & Logical Operators

Welcome to **Day 03** of the Python learning journey!
Today focuses on decision-making in programs using conditional statements.

---

## 📚 Topics Covered

- Conditional statements (`if`, `elif`, `else`)
- Comparison and modulo operations
- Nested conditionals
- Multiple `if` statements
- Logical operators (`and`, `or`, `not`)
- Building interactive decision-based programs

---

---

## 🎯 Learning Goal

By the end of Day 03, you should be able to:

- Control program flow using conditions
- Use modulo and comparison operators effectively
- Build nested decision structures
- Combine multiple logical checks
- Create simple interactive programs
