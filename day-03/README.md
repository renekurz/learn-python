# 🐍 Day 03 – Control Flow & Logical Operators

Welcome to **Day 03** of the Python learning journey!
Today focuses on making decisions in programs using conditional statements, logical operators, and nested control flow.

---

## 📚 Topics Covered

- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Logical operators (`and`, `or`, `not`)
- Nested conditionals
- Scope & indentation importance
- Building interactive decision-based programs

---

## 📂 Files Overview

| File                           | Description                                   |
| ------------------------------ | --------------------------------------------- |
| `01-conditional-statements.py` | Introduction to `if`, `elif`, and `else`      |
| `02-comparison-operators.py`   | Using comparison operators in conditions      |
| `03-logical-operators.py`      | Combining conditions with logical operators   |
| `04-nested-conditionals.py`    | Structuring complex decision trees            |
| `05-multiple-if-statements.py` | Understanding multiple independent conditions |
| `06-leap-year.py`              | Real-world logic exercise (leap year checker) |

| `08-treasure-island.py`        | Interactive text-based adventure game         |

---

## 🎯 Learning Goal

By the end of Day 03, you should be able to:

- Control program flow using conditional logic
- Combine multiple conditions effectively
- Structure nested decision trees
- Write interactive programs based on user choices
- Design simple logic-driven mini games

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-03
python3 08-treasure-island.py
```
