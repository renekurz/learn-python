# 🐍 Day 09 – Dictionaries, Nesting & Blind Auction

Welcome to **Day 09** of the Python learning journey!
Today focuses on working with **dictionaries**, understanding **nested data structures**, and building a real mini-project: the **Blind Auction program**.

---

## 📚 Topics Covered

- Creating and modifying dictionaries
- Looping through dictionary data
- Nesting lists inside dictionaries
- Nesting dictionaries inside dictionaries
- Structuring real-world data
- Building logic for a multi-user bidding system

---

By the end of Day 09, you should be able to:


## 🧠 Mini Project

The **Blind Auction** project simulates a secret bidding system where:

- Multiple users can place bids
- The program stores bids using dictionaries
- The highest bidder is determined automatically

Try enhancing it by:

- Adding bid validation
- Supporting multiple auction rounds
- Saving bids to a file
- Improving the user interface
