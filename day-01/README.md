# 🐍 Day 01 – Python Basics

Welcome to **Day 01** of the Python learning journey!
This day introduces the fundamental building blocks of Python programming, including printing, strings, user input, debugging, and variables.

---

## 📚 Topics Covered

- Running your first Python program
- Using the `print()` function
- String manipulation & formatting
- Debugging common syntax errors
- Getting user input with `input()`
- Working with variables
- Basic problem-solving exercises

---

## 📂 Files Overview

| File                        | Description                                              |
| --------------------------- | -------------------------------------------------------- |
| `01-hello-world.py`         | Your first Python program — printing text to the console |
| `02-printing-practice.py`   | Practice using `print()` correctly with formatting       |
| `03-string-manipulation.py` | Learn newline characters and string concatenation        |
| `04-debugging-practice.py`  | Fix syntax and logical errors in code                    |
| `05-input-function.py`      | Collect and use user input                               |
| `06-python-variables.py`    | Introduction to variables and `len()`                    |
| `07-exercise-variables.py`  | Variable swapping exercise                               |
| `08-band-name-generator.py` | Mini project combining input + strings                   |

---

## 🎯 Learning Goal

By the end of Day 01, you should be able to:

- Write and run simple Python scripts
- Print formatted output
- Take user input and use it in programs
- Understand basic variables and string operations
- Debug simple syntax mistakes

---

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python3 filename.py
```

Example:

```bash
cd day-01
python3 01-hello-world.py
```
