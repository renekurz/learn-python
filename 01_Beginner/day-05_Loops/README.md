# 🐍 Day 05 – Python Loops

Welcome to **Day 05** of the Python learning journey!
Today introduces loops for repeating actions and working with iterable data.

---

## 📚 Topics Covered

- The `for` loop
- Iterating through sequences
- Finding maximum values
- The `range()` function
- Loop-based problem solving
- Building a password generator

## 🎯 Learning Goal

By the end of Day 05, you should be able to:

- Use loops to repeat tasks efficiently
- Iterate through lists and ranges
- Solve simple algorithmic challenges
- Combine loops with conditional logic
- Build small practical projects with repetition
