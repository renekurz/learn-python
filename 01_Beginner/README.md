# 🟢 01 Beginner — Days 1 – 14

Welcome to the **Beginner section** of the Python learning journey!

These 14 days cover the absolute fundamentals of Python — from printing your first line of code to building complete interactive mini games. Each day introduces one or two new concepts and immediately applies them in a small project.

---

## 🎯 What You'll Learn

By the end of this section you will be able to:

- Write and run Python scripts confidently
- Work with all core data types and convert between them
- Control program flow with conditions and loops
- Define functions that take inputs and return outputs
- Use lists and dictionaries to manage collections of data
- Structure programs across multiple files using modules
- Debug programs systematically
- Build complete console-based games and utilities

## 🧠 Key Projects

### 🎮 Hangman (Day 7)
The first larger multi-file project. A complete word guessing game with lives, ASCII art, random word selection, and win/lose conditions. Combines loops, conditionals, lists, and external modules.

### 🔐 Caesar Cipher (Day 8)
A classic encryption/decryption program. Built incrementally — first encryption only, then decryption, then combined, then refactored — teaching the value of iterative development.

### 🃏 Blackjack (Day 11)
A fully playable Blackjack game against a dealer. Covers card drawing, score calculation including Ace handling, and win/draw/lose conditions. The first real capstone project.

### ⬆️ Higher Lower Game (Day 14)
A follower-comparison guessing game. Uses an external data module and maintains a score streak. The final project of the beginner section.

## 🚀 How to Run

Make sure Python 3 is installed, then navigate to any day's folder and run:

```bash
python3 <filename>.py
```

No external packages are required for this section — everything uses Python's standard library.
